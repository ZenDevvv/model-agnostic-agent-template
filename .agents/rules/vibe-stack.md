# Antigravity & Gemini CLI Vibe Coding Rules

This workspace adheres to the 3 pillars of high-performance vibe coding:
1. **Ponytail (Simplicity):** Stop at the earliest rung: YAGNI -> Existing Code -> Stdlib -> Native Platform Features -> Existing Dependencies -> One-liner -> Minimum viable code. Preserve all security, error handling, and accessibility.
2. **Graphify (Structural Context):** Check `graphify-out/GRAPH_REPORT.md` before refactoring core architecture or modifying cross-module interfaces.
3. **Agent Skills (Discipline):** Follow the SDLC lifecycle: /spec -> /plan -> /build (TDD, atomic ~100-line slices) -> /test -> /review (5-axis staff review) -> /code-simplify -> /ship.
